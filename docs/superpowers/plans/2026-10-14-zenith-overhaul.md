# "!!!!!" — THE ABSOLUTE overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** THE ABSOLUTE flies and dives, fights with a humanoid arsenal, looks like a boxer of light (stance, red eyes, glowing gauntlets) in a blood-sunset arena renamed "!!!!!", and every move can be read by ear (wind-up, cue, boom); the sword's overhead swing points the right way.

**Architecture:** Flight is an altitude (`abAlt`) layered on the existing string machine in `EnemyAbsolute.h`: air moves are steps flagged `air`, any ground step lands him first, and one function (`abFly`) owns his height. The new moves are rows in the same string table. All per-move sound and impact data lives in one table (`AbsoluteFeel.h`, no audio/GL) that the game (`Gameplay_Absolute.h`) and the tests read; the mind only emits events (`ev.abCue`, `ev.abImpact`, `ev.abTakeoff`, ...). New sounds are synthesised in `tools/sfx_absolute.py` (imported by `tools/gen_sfx.py`) and listed in `MixTable.h`.

**Tech Stack:** C++17 header-only game code (GLM, OpenGL 3.3 / GLES3), headless tests in `tests/test_zenith.cpp` (+ `tests/BossSim.h`), Python 3 stdlib sound synthesis, ffmpeg for checking sounds.

**Spec:** `docs/superpowers/specs/2026-10-14-zenith-overhaul-design.md`

## Global Constraints

- Branch `zenith-overhaul` (exists, holds the spec). Every task ends with `make && make test` green and one commit.
- Commit messages carry **no** Co-Authored-By / Claude trailers (the user's rule). Never push without asking the user.
- No `rand()`/`frand()` in THE ABSOLUTE's mind (`EnemyAbsolute.h`): tests must be deterministic across glibc and macOS (a rand()-dependent test broke Linux CI before). Use `age`, `abRot` or hashes of them.
- Colour rule unchanged: white = parry, gold = dodge/block, red = leave the area. Red strikes reach the sword as `Sword::Strike::AREA` (never blocked).
- Tell floors unchanged: 0.35 s opener, 0.22 s follow-up (`TELL_FLOOR`, `AB_FOLLOW_FLOOR`).
- The cue fires when a telegraphed move's remaining tell reaches **`AB_CUE = 0.22f`** s.
- A whole phase-1 string taken costs **at most 70**; the longest phase-1 ground strings cost 60–70. Single hits 14–30.
- Flight: cruise 9–14 m, orbit 14–20 m from you, at most **5 s** airborne per flight (test: never over 6 s), shot down at **6 %** of max hp dealt in one flight → staggered **1.5 s** at ×1.5.
- BossSim's solid player kills him in **150–180 s**; guns-only dodger still wins (slower); standing still dies within 30 s.
- On-screen level name is literally **`!!!!!`** (`ZENITH_NAME`). Code identifiers (`ZENITH_ARENA`, `level.zenith`, the ZENITH music track) keep their names. The boss stays **THE ABSOLUTE**.
- Lines: "KNEEL.", "TOO SLOW.", "AGAIN.", "...WORTHY." only. "BE JUDGED." is gone.
- New sound files are only ever (re)generated by name: `python3 tools/gen_sfx.py <names>` — running it with no arguments re-rolls every sound, including ones replaced by recordings.
- Code style: match the files — terse comments in the existing voice, header-only `inline`, `// ----` section rules, numbers as `constexpr` near their users.

## Review Focus

1. **A phase change, a parry, a stagger or the last judgment while he's in the air** → he comes down (no hovering in a stagger, never under the floor). Test in Task 4 ("interrupted in the air, he always comes down").
2. **His death mid-flight** → the kneeling corpse is on the floor, the flight wind stops. Code in Task 9 (`onAbsoluteKilled` grounds `abCorpse`, stops `abFlightH`), checked in the Task 10 dev run.
3. **A retry after a SKYFALL broke a shard** → the shard is back (`restoreZenith`) and no flight/beam sound is left playing. Test in Task 5 ("a retry brings a broken shard back"); sound handles cleared in Task 9's retry hook.
4. **Hard difficulty / phase-2 speed-ups shortening tells** → each telegraphed move's cue still fires exactly once, never before the tell starts. Test in Task 7 ("one cue per move, every difficulty and phase").
5. **A SKYFALL mark or a METEOR landing next to a pillar or the floor's edge** → he never ends up inside a pillar or past the edge. Test in Task 5 ("a dive beside a pillar never lands in it").

```cpp
// His height: eased toward where it's going (fast in a dive or a fall), set over
// whatever floor is under him. The one place his Y is decided.
inline void Enemy::abFly(float dt, const EnemyWorld& w) {
    if (staggered()) { abAltWant = 0.f; abDiving = true; }
    float rate = abDiving ? AB_DIVE_V : abAltWant < abAlt ? AB_FALL_V : AB_CLIMB;
    abAlt += glm::clamp(abAltWant - abAlt, -rate * dt, rate * dt);
    if (abAlt > 0.5f) abAirT += dt;
    else { abAirT = 0.f; abFlightHp = -1.f; if (abAltWant <= 0.f) abDiving = false; }
    position.y = (w.hasZenith ? absFloorAt(w, position) : abCentre.y) + abAlt;
}
// Up there: round you at 14-20 m, never past the floor's edge, round a pillar (or over one)
inline void Enemy::abOrbit(float dt, const EnemyWorld& w, glm::vec3 feet) {
    glm::vec3 from = position - feet; from.y = 0.f;
    float r = glm::length(from);
    glm::vec3 dir = r > 0.1f ? from / r : glm::vec3{std::sin(yaw), 0.f, std::cos(yaw)} * -1.f;
    glm::vec3 side{-dir.z * abOrbitDir, 0.f, dir.x * abOrbitDir};
    glm::vec3 goal = feet + dir * glm::clamp(r, AB_ORBIT_LO + 0.5f, AB_ORBIT_HI - 0.5f) + side * 5.f;
    glm::vec3 g = goal - position; g.y = 0.f;
    float l = glm::length(g);
    if (l > 0.05f) {
        glm::vec3 p = position + g / l * std::min(l, AB_RUN * 1.4f * dt);
        p = abAlt >= AB_OVER ? absSafeXZ(EnemyWorld{}, p, position) : absSafeXZ(w, p, position);
        if (w.hasZenith) {   // (over the pillars only the edge matters)
            glm::vec2 d{p.x - abCentre.x, p.z - abCentre.z};
            if (glm::length(d) > AB_FLOOR_R) { d *= AB_FLOOR_R / glm::length(d); p.x = abCentre.x + d.x; p.z = abCentre.z + d.y; abOrbitDir = -abOrbitDir; }
        }
        position.x = p.x; position.z = p.z;
        moveSpeed = AB_RUN * 1.4f;
    }
    turnToward(feet - position, dt, 10.f);
}

}
```

```python
"""
THE ABSOLUTE's sounds (imported by gen_sfx.py): his wind-ups, the cues that
say what to do (ting: parry; doom: dodge or block; pulse: get out), the booms
of his blows, his flight, and the player's side (parry clang, break, creak,
the timing tick, the wrong buzz). Each is built from a few layers so they read
apart: the swishes are noise, the gold is low and growling, the reds buzz,
the booms are sub drops with a crack and an open-sky tail.
"""
import math
import random

SR = 44100


def n(sec):
    return int(SR * sec)


def env(i, total, attack, release, curve=1.0):
    """0..1: a linear attack, a hold, a release at the end, raised to curve"""
    a = min(1.0, i / max(1, n(attack)))
    r = min(1.0, (total - i) / max(1, n(release)))
    return (min(a, r)) ** curve


def sweep(f0, f1, length, curve=1.0):
    """Phase-accumulated sine sweeping f0 -> f1 (curve > 1: late, < 1: early)"""
    out, ph = [], 0.0
    for i in range(length):
        u = (i / max(1, length - 1)) ** curve
        f = f0 + (f1 - f0) * u
        ph += 2 * math.pi * f / SR
        out.append(math.sin(ph))
    return out


def saw(f, i):
    x = (f * i / SR) % 1.0
    return 2 * x - 1


def square(f, i):
    return 1.0 if (f * i / SR) % 1.0 < 0.5 else -1.0


def noise(length):
    return [random.uniform(-1, 1) for _ in range(length)]


def onepole_lp(x, fc):
    a = 1 - math.exp(-2 * math.pi * fc / SR)
    y, p = [0.0] * len(x), 0.0
    for i, s in enumerate(x):
        p += a * (s - p)
        y[i] = p
    return y


def onepole_hp(x, fc):
    lp = onepole_lp(x, fc)
    return [s - l for s, l in zip(x, lp)]


def bandsweep(x, f0, f1, q=4.0):
    """State-variable band-pass whose centre sweeps f0 -> f1 across x"""
    low = band = 0.0
    y = []
    L = len(x)
    for i, s in enumerate(x):
        fc = f0 + (f1 - f0) * i / max(1, L - 1)
        f = 2 * math.sin(math.pi * min(fc, SR / 6) / SR)
        high = s - low - band / q
        band += f * high
        low += f * band
        y.append(band)
    return y


def drive(x, k):
    return [math.tanh(s * k) / math.tanh(k) for s in x]


def gain(x, g):
    return [s * g for s in x]


def add(*tracks):
    L = max(len(t) for t in tracks)
    out = [0.0] * L
    for t in tracks:
        for i, s in enumerate(t):
            out[i] += s
    return out


def pad(x, length):
    return x + [0.0] * max(0, length - len(x))


def tail(x, seconds, decay=0.55, wet=0.35, damp=3500.0):
    """An open-sky echo: four damped combs and two all-passes (Schroeder), x padded by `seconds`"""
    x = pad(x, len(x) + n(seconds))
    out = [0.0] * len(x)
    for d_ms in (29.7, 37.1, 41.1, 43.7):
        d = n(d_ms / 1000.0)
        buf, lp = [0.0] * len(x), 0.0
        a = 1 - math.exp(-2 * math.pi * damp / SR)
        for i in range(len(x)):
            fb = buf[i - d] if i >= d else 0.0
            lp += a * (fb - lp)
            buf[i] = x[i] + lp * decay
            out[i] += buf[i] * 0.25
    for d_ms, g in ((5.0, 0.7), (1.7, 0.7)):
        d = n(d_ms / 1000.0)
        y = [0.0] * len(out)
        for i in range(len(out)):
            xd = out[i - d] if i >= d else 0.0
            yd = y[i - d] if i >= d else 0.0
            y[i] = -g * out[i] + xd + g * yd
        out = y
    return [dry * (1 - wet) + w * wet for dry, w in zip(x, out)]


def fit(x, seconds):
    """Exactly `seconds` long, with a 10 ms fade at the end"""
    L = n(seconds)
    x = pad(x[:L], L)
    f = n(0.01)
    for i in range(f):
        x[L - 1 - i] *= i / f
    return x


# ---- wind-ups: white (swishes), gold (growl), red (whine, rumble) -------------------------------

def _swish(sec, f0, f1, swell=2.2, flutter=0.0):
    L = n(sec)
    b = bandsweep(noise(L), f0, f1, q=3.0)
    return [s * (i / L) ** swell * (1 + flutter * math.sin(2 * math.pi * 9 * i / SR)) * (1.0 if i < L - n(0.012) else (L - i) / n(0.012))
            for i, s in enumerate(b)]


def gen_ab_wind_jab():
    return fit(gain(_swish(0.30, 800, 3500, 2.6), 1.4), 0.30)


def gen_ab_wind_cross():
    L = n(0.35)
    zip_ = [s * (i / L) ** 2.5 * 0.35 for i, s in enumerate(sweep(300, 1400, L, 1.6))]
    return fit(add(gain(_swish(0.35, 700, 3800, 2.8), 1.4), zip_), 0.35)


def gen_ab_wind_hook():
    return fit(gain(_swish(0.45, 400, 2000, 1.8, 0.35), 1.5), 0.45)


def gen_ab_wind_spin():
    L = n(0.50)
    base = bandsweep(noise(L), 600, 2600, q=2.5)
    out, ph = [], 0.0
    for i, s in enumerate(base):
        u = i / L
        ph += 2 * math.pi * (6 + 16 * u) / SR
        out.append(s * (0.5 + 0.5 * math.sin(ph)) ** 2 * u ** 1.4 * 1.8)
    return fit(out, 0.50)


def gen_ab_wind_meteor():
    L = n(0.60)
    chord = [0.0] * L
    for f in (1318.5, 1975.5, 2637.0):
        ph = 0.0
        for i in range(L):
            ph += 2 * math.pi * f * (1 + 0.006 * math.sin(2 * math.pi * 6 * i / SR)) * (1 + 0.15 * i / L) / SR
            chord[i] += math.sin(ph) * 0.22 * (i / L) ** 1.5
    roar = [s * (i / L) ** 2 * 0.9 for i, s in enumerate(onepole_lp(noise(L), 900))]
    return fit(add(chord, roar), 0.60)


def gen_ab_wind_blade():
    L = n(0.45)
    a, b = sweep(880, 1175, L, 0.8), sweep(887, 1183, L, 0.8)
    hiss = gain(onepole_hp(noise(L), 5000), 0.08)
    return fit([(x + y) * 0.35 * (i / L) ** 1.2 + h for i, (x, y, h) in enumerate(zip(a, b, hiss))], 0.45)


def gen_ab_thrum():
    """Gold: a deep growl swelling, a dragged gong - nothing bright"""
    L = n(0.80)
    growl = drive([saw(55 * (1 + 0.01 * math.sin(2 * math.pi * 4 * i / SR)), i) for i in range(L)], 2.5)
    growl = onepole_lp(growl, 400)
    gong = [0.0] * L
    for mult, amp in ((1.0, 0.5), (2.76, 0.28), (5.4, 0.12)):
        ph = 0.0
        for i in range(L):
            ph += 2 * math.pi * 110 * mult * (0.97 + 0.03 * i / L) / SR
            gong[i] += math.sin(ph) * amp
    return fit([(g * 0.7 + o * 0.5) * (i / L) ** 1.6 for i, (g, o) in enumerate(zip(growl, gong))], 0.80)


def gen_ab_whistle():
    L = n(0.75)
    wh = sweep(2400, 500, L, 0.6)
    air = onepole_lp(noise(L), 1500)
    return fit([(w * 0.5 + a * 0.5 * (i / L)) * (0.3 + 0.7 * (i / L)) for i, (w, a) in enumerate(zip(wh, air))], 0.75)


def gen_ab_ray_charge():
    L = n(0.65)
    wh = sweep(300, 1800, L, 1.3)
    buzz = onepole_lp([saw(70, i) for i in range(L)], 900)
    return fit([(w * 0.45 + b * 0.35) * (i / L) ** 1.3 for i, (w, b) in enumerate(zip(wh, buzz))], 0.65)


def _crackle(L, density_end=0.004, density_start=0.0005):
    out = [0.0] * L
    for i in range(L):
        dens = density_start + (density_end - density_start) * i / L
        if random.random() < dens:
            amp = random.uniform(0.4, 1.0)
            for k in range(min(n(0.004), L - i)):
                out[i + k] += random.uniform(-1, 1) * amp * (1 - k / n(0.004))
    return out


def gen_ab_rumble():
    L = n(0.90)
    rum = gain(onepole_lp(onepole_lp(noise(L), 120), 120), 6.0)
    return fit([(r + c * 0.4) * (i / L) ** 1.1 for i, (r, c) in enumerate(zip(rum, _crackle(L)))], 0.90)

    L = n(0.35)
    out = []
    for i in range(L):
        t = i / SR
        a = min(1.0, i / n(0.001))
        s = (math.sin(2 * math.pi * 2637 * t) * math.exp(-9 * t) + math.sin(2 * math.pi * 2637 * 2.76 * t) * 0.35 * math.exp(-16 * t)
             + math.sin(2 * math.pi * 2637 * 5.4 * t) * 0.15 * math.exp(-28 * t))
        s *= 1 + 0.15 * math.sin(2 * math.pi * 18 * t)
        out.append(s * a * 0.8)
    return fit(out, 0.35)


def gen_ab_doom():

    L = n(0.45)
    thump = sweep(90, 45, L, 0.5)
    out = []
    for i in range(L):
        t = i / SR
        click = math.sin(2 * math.pi * 400 * t) * math.exp(-60 * t) * 0.5

def gen_ab_pulse():

    L = n(0.30)
    out = [0.0] * L
    for start in (0.0, 0.09):
        s0 = n(start)
        for k in range(n(0.06)):
            out[s0 + k] = square(1000, k) * 0.6 * min(1.0, k / 40) * min(1.0, (n(0.06) - k) / 40)
    return fit(onepole_lp(out, 6000), 0.30)

def _boom(sub0, sub1, sub_len, crack_len, crack_lp, tail_s, sub_amp=1.0, crack_amp=0.7, drive_k=1.5, decay=0.55):
    L = n(sub_len)
    sub = sweep(sub0, sub1, L, 0.45)
    sub = [s * math.exp(-4.5 * i / L) * sub_amp for i, s in enumerate(sub)]
    C = n(crack_len)
    crack = onepole_lp([random.uniform(-1, 1) * math.exp(-6 * k / C) for k in range(C)], crack_lp)
    crack = gain(crack, crack_amp * 2.5)
    return tail(drive(add(sub, crack), drive_k), tail_s, decay=decay)

def gen_ab_takeoff():
    L = n(1.2)
    roar = []
    lp, fc = 0.0, 300.0
    for i in range(L):
        fc = 300 + 2700 * (i / L) ** 0.7
        a = 1 - math.exp(-2 * math.pi * fc / SR)
        lp += a * (random.uniform(-1, 1) - lp)
        roar.append(lp * env(i, L, 0.15, 0.5) * 1.6)
    choir = [0.0] * L

            ph += 2 * math.pi * f * (1 + 0.008 * math.sin(2 * math.pi * 5.5 * i / SR + f)) / SR
            choir[i] += (math.sin(ph) + 0.3 * math.sin(2 * ph)) * 0.16 * env(i, L, 0.4, 0.5)

def gen_ab_flight():
    L = n(6.0)
    base = noise(L)
    out, low, band = [], 0.0, 0.0
    for i, s in enumerate(base):
        fc = 1000 + 500 * math.sin(2 * math.pi * 0.37 * i / SR) * math.sin(2 * math.pi * 0.11 * i / SR + 1)
        f = 2 * math.sin(math.pi * fc / SR)
        high = s - low - band / 5.0
        band += f * high
        low += f * band
        out.append(band * env(i, L, 0.3, 0.3) * 0.9)
    return fit(out, 6.0)


def gen_ab_shotdown():
    L = n(1.5)
    wail = sweep(900, 150, L, 0.8)

    C = n(0.01)
    crack = [random.uniform(-1, 1) * math.exp(-6 * k / C) * 1.5 for k in range(C)]
    return fit(add(tail(crack, 0.5), wail), 1.5)
```
